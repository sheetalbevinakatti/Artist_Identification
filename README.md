# Artist Identification Using Machine Learning

## Project Title
Comparison of Machine Learning Techniques for Artist Identification

## Objective
This project reproduces the machine learning approaches described in the reference paper "Comparison of Machine Learning Techniques for Artist Identification".

The project will reproduce:
1. SVM with handcrafted image features
2. CNN for image classification

The project will then extend the reference work by implementing:
3. ResNet50 using transfer learning

## Reference Paper
Comparison of Machine Learning Techniques for Artist Identification

## Dataset
Painters by Numbers dataset.

## Task
Given an image of a painting, predict the artist who created it.

## Models
- SVM with image feature extraction
- CNN
- ResNet50 Transfer Learning

## Evaluation
Models will be compared using:
- Test accuracy
- Training accuracy
- Training time
- Inference time
- Confusion matrix
